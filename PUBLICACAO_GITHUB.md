## Histórico original

A integração disponível envia objetos e arquivos pela API do GitHub. A importação tem seus próprios commits no GitHub. Os nove commits originais, incluindo datas e hashes, são preservados sem alteração no arquivo historico.bundle.

Para recuperar o repositório original completo:

```bash
git clone historico.bundle lumiere-elevee-original
cd lumiere-elevee-original
git log --oneline
```

O último commit original é b26105ee444646b7f5dd9c90736d2833698fa2d9. Nenhuma data do histórico original foi alterada.

Para executar o site a partir do clone normal do GitHub, consulte README.md. Não é preciso restaurar o bundle para abrir o projeto; ele serve para consultar e recuperar o histórico anterior à importação.
