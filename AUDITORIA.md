# Auditoria — Lumière Élevée

O site existente foi inspecionado, incluindo HTML, CSS, JavaScript, dados, caminhos e histórico Git. A identidade visual e as funcionalidades existentes devem ser preservadas.

| Critério | Situação encontrada | Trabalho necessário |
| --- | --- | --- |
| 1. Organização | Arquivos em dist, sem separação css/js/img | Organizar pastas e caminhos |
| 2. Identidade | Nome, paleta, tipografia e imagens locais próprios | Preservar |
| 3. Produtos | Cinco produtos em seis coleções | Ampliar para pelo menos três categorias com três produtos |
| 4. Navegação | Busca, categorias, detalhes e avisos existentes | Revalidar após as alterações |
| 5. Carrinho | Quantidades, remoção e persistência existentes | Cálculos em centavos e preço unitário: corrigidos nesta etapa |
| 6. Checkout | Nome, e-mail e endereço apenas | Completar telefone, CPF fictício, CEP, cidade e estado |
| 7. Pagamento | Cartão, Pix e boleto ilustrativos | Implementar débito/crédito, campos fictícios, parcelas, Pix e cópia |
| 8. Código | HTML semântico; JS e CSS muito compactos | Formatar, comentar e simplificar funções |
| 9. Git | Histórico existente preservado | Commits por etapa; definir repositório GitHub de destino |
| 10. Responsividade | Desktop e 390 px verificados na versão anterior | Revalidar 360, 768 e 1280 px após a implementação |

## Ordem de implementação
1. Corrigir valores e informações da sacola.
2. Completar checkout e validações.
3. Completar pagamentos simulados e parcelamento.
4. Ampliar catálogo, organizar e comentar código.
5. Criar README e EXPLICACAO, testar casos de borda e atualizar a hospedagem privada.

## Limites desta etapa
Esta auditoria não certifica atendimento integral ao enunciado. A versão hospedada anterior continua disponível. Ainda não foi fornecido um repositório GitHub de destino; nenhum repositório existente foi alterado.
